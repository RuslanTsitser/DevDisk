Support

For bugs and feature requests, use GitHub Issues.

Include in a bug report Your macOS version, DevDisk version, selected scan scope, expected result, and steps to reproduce the problem.

Privacy when reporting issues

Do not attach CSV reports, screenshots, project names, usernames, or filesystem paths unless you have reviewed and redacted them first.

Sandbox limitations

DevDisk can scan only the folder or volume you select in the macOS picker. Some protected system directories may remain unavailable; the app marks them as unavailable rather than showing them as empty.
