# DevDisk Privacy Policy

Effective: August 11, 2026

DevDisk does not collect, transmit, sell or share personal data. Scans, file paths, security-scoped bookmarks and scan history remain on the user's Mac. CSV reports are created only when the user explicitly exports them to a chosen location.

DevDisk contains no analytics SDK, advertising SDK, account system or payment system. It does not send developer artifact data to package managers or cloud services.

Questions can be opened in the [public support tracker](https://github.com/RuslanTsitser/DevDisk/issues).
