# DevDisk Support

For bugs and feature requests, use [GitHub Issues](https://github.com/RuslanTsitser/DevDisk/issues). Include your macOS version, DevDisk version, the selected scan scope and reproducible steps. Do not attach CSV reports or paths that contain private project names unless you have reviewed them first.

DevDisk is sandboxed. Full-disk results depend on the folder or volume access granted in the macOS picker, and macOS may keep protected directories inaccessible.
